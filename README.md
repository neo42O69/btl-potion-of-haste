I was short on stone, so I decided to go mining. My efficiency 5 pickaxe made little difference with efficiency 4, since they both don't instamine.

It would shine if I had haste 2, which requires beating the wither and other pricey things.

Therefore I decided to add the haste potion. Since I added the haste potion, I also added the mining fatigue potion.

# ABOUT

The haste potion is brewed, like any other potion, in a brewing stand. You need to brew an **awkward potion** with some **cocoa beans**

It can be corrupted with a **fermented spider eye**, which gives you the potion of mining fatigue.

Again, just like any potion, they can be extended with redstone dust or upgraded with glowstone dust.

With an efficiency 5 diamond or netherite pickaxe and haste 2, you can **instamine** stones such as diorite, andesite, granite, tuff, stone, and more.
